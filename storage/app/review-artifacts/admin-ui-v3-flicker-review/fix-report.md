# GEOFlow UI V3 页面闪跳修复报告

## 根因与修复

### 1. 侧栏状态在首屏后才应用

公共脚本原先在页面就绪后读取本地存储，浏览器先按展开态排版，再切换到用户保存的状态，侧栏和正文同步横移。

修复内容：

- 在公共布局的 CSS 加载前读取 `geoflow.admin.ui-v3.sidebar-collapsed`。
- 将结果写入 `<html data-gf-sidebar-state="expanded|collapsed">`。
- 首屏初始化阶段关闭过渡，下一帧恢复交互动画。
- 客户端脚本信任服务端页面头部已经确定的初始状态，只在用户点击后写回本地存储。

### 2. 图标替换改变首屏占位

Lucide 图标替换前的 `i[data-lucide]` 缺少稳定尺寸，多个页面还会重复执行全局图标扫描，引发按钮、标题和文本换行变化。

修复内容：

- 为公共控件、侧栏、AI 工作台和动态区域设置精确图标占位。
- 新增 `GeoFlowAdminUi.refreshIcons(root)`，限定刷新到新增节点。
- 删除 80ms 二次全局扫描。
- 对旧页面直接调用 `lucide.createIcons()` 的场景增加兼容封装，已转换图标不再被重复处理。
- 增加 4 个图标刷新单元测试。

### 3. 公共入口加载链路过长

文章助手、分析、人工发布、AI 工作台、Echo 和二维码库原先进入公共资源链路，普通页面首屏也承担额外下载和执行成本。

修复内容：

- 公共壳层和稳定样式优先加载。
- 四类页面能力按 DOM 特征动态加载。
- Echo 只在任务页和 AI 工作台加载。
- 二维码库在用户打开二维码弹窗时加载。
- 公共应用脚本缩减到约 49.65 kB，页面能力拆分为独立哈希资源。

### 4. 异步区域和错误提示造成二次排版

文章编辑器、企业知识编辑器和 AI 工作台异步提示在加载后改变高度。

修复内容：

- 为两个编辑器预留确定的首屏高度。
- AI 工作台运行时提示采用固定浮层反馈，错误出现时不推挤标题、建议区和输入框。
- 为滚动区域启用稳定滚动条槽位。
- AI 任务动画仍在用户提交任务后启动。

### 5. 本地静态资源缺少独立缓存入口

修复内容：

- 新增 UI V3 专用 Nginx 服务，继续使用 28080。
- 哈希资源使用一年 immutable 缓存。
- 普通静态资源使用短缓存。
- 动态 HTML 和代理响应使用 no-store。
- 普通页面请求统一转发给 Laravel，避免根目录被误当成静态目录。
- 显式阻止 PHP 源文件和隐藏配置文件访问。
- 在动态页面、哈希资源和普通静态资源上统一返回安全响应头。
- 应用容器采用 4 个本地工作进程，降低长请求阻塞逐页检查的概率。
- UI V3 容器、网络和端口继续与 18080 稳定版隔离。

## 兼容性

- 保持 Laravel 服务端完整页面导航。
- 保持现有本地存储键。
- 保持数据库结构、公开 API 和业务路由不变。
- 保持 AI 工作台当前未提交后端开发文件原样。
- 保持稳定版 18080 的代码、容器和数据不变。

## 自查结果

- 安全：首屏脚本只读取固定本地存储键并写入枚举属性值；Nginx 只直接提供明确的静态资源，并阻止 PHP 与隐藏文件读取；审查产物仅保留允许检查的响应头，不记录 Cookie；未新增外部密钥和公开接口。
- 架构：公共壳层状态只有一个来源；页面模块按需加载；动态图标使用局部刷新入口。
- 交互：展开、收起、移动抽屉、刷新、跨页和历史导航均通过复验。
- 对抗检查：本地存储不可用时回退展开态；Lucide 未加载时保留稳定占位；长错误文案在浮层内滚动；降低动态效果模式继续禁用过渡。
