## 已验证场景

- 展开态第一帧直接采用 256px 侧栏和对应正文起点。
- 收起态第一帧直接采用 72px 侧栏和对应正文起点。
- 移动端保留收起偏好，同时以抽屉布局渲染，不挤压正文。
- 页面刷新、新标签、跨页、浏览器前进和后退均保持侧栏状态。
- Lucide 图标转换前后保留相同占位，页面内无待转换图标。
- 长短页面切换保持稳定滚动条槽位。
- 编辑器、AI 工作台及异步区域具有首屏稳定空间。
- 哈希静态资源返回一年 immutable 缓存，HTML 返回 no-store。
- 18080 与 28080 可同时访问，两个环境保持隔离。

## 运行时限制

AI 工作台的页面布局在六档视口全部通过，CLS 范围为 0.000022 至 0.000099。当前保留中的 AI 工作台后端开发内容尚未完成数据库迁移，`GET /admin/ai-workspace/conversations` 返回 500，因此浏览器综合结果记录为 492 通过、6 个运行时阻塞。

该接口响应还会把底层数据库错误文案传到前端。按照本轮约束，AI 工作台未提交后端文件和数据库迁移保持原样，这项运行时问题未纳入闪跳修复提交。完成 AI 工作台运行时迁移前，应关闭该接口的详细错误输出，并补充 JSON 错误响应测试。
